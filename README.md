# Saman Karimi Portfolio

Updated recruiter-facing portfolio website.

## Publish with GitHub Pages

1. Upload `index.html` to the root of the `saman-karimi-portfolio` repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose `main` and `/root`.
5. Save and wait for the public URL to become active.
